# SPL Token Playground

Simple playground for testing basic SPL token concepts on Solana devnet.

## Goals

- Understand how SPL tokens work
- Test wallet interactions
- Prepare basic token experiments
- Keep development separated from production environments

## Planned Tests

- Create a devnet wallet
- Request devnet SOL
- Create a test token
- Mint test supply
- Send test tokens between wallets

## Environment

This project is intended for Solana devnet only.

No mainnet assets are used in this repository.
